# Cyan Garden

A Gray-Scott reaction-diffusion simulation in one HTML file. Open `index.html`.

Two chemicals diffuse and react: `U` feeds `V`, and `V` consumes `U` to reproduce. Tiny changes to the feed (F) and kill (k) rates flip the system between coral labyrinths, dividing cells, spots, worms and travelling waves. Nobody draws any of it.

- Click or drag to paint organism into the dish.
- Buttons switch preset regimes; `reseed` scatters fresh seeds.
- `?p=mitosis&warm=3000` opens a preset pre-grown by N steps.
